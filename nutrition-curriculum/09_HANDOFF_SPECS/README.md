# Handoff Specs

One file per DEC currently tracked in `../IMPLEMENTATION_HANDOFF.md`. Named `DEC-###-<slug>.md`, e.g.
`DEC-025-body-composition-metrics.md`.

Written by the planner before a row is set to `PUSHED`. Read `_TEMPLATE.md` for the shape every spec
should follow — copy it, don't reinvent the structure per DEC.

A finished spec file is never deleted once its row reaches `DONE` — it stays as the record of what was
actually asked for, next to `IMPLEMENTATION_HANDOFF.md`'s Closed archive entry for the same DEC.
