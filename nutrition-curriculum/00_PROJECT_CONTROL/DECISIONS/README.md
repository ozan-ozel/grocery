# Decisions

Holds the recorded human decisions for this project — review-gate outcomes and any other decision a human
made that the AI must not re-decide.

Still-open human decisions are tracked in their originating artifacts, not here:

- `03_PHASE_1_CURRICULUM_ANALYSIS/PHASE_1_AMBIGUITY_AUDIT.md` ("Human Decisions" section)
- `04_PHASE_2_CURRICULUM_ARCHITECTURE/PHASE_2_HUMAN_REVIEW.md`

Once a decision is made, record it here as its own dated file. This folder now contains the Gate 1–6
decision records (2026-09-05 through 2026-09-07) and one non-gate record — the Phase 9 safety-decision
ratification of 2026-09-07 — which is explicitly labelled as a ratification rather than a Review Gate.
Not every file here is a gate; each record states which it is.
