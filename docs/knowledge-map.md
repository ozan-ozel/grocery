## Routing

Start with the repository's primary instruction or README. Follow the relevant canonical source. Do not duplicate canonical content here.

## Escalation

A recurring local problem may become architecture-shaped when repeated evidence shows that local fixes do not address the underlying constraint. Record the evidence first; create or update a decision source only when the repository's governance supports it.
