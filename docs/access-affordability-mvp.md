# Access and Affordability — MVP Scope

Domain S is `DEC-106` and `DEC-107`. They are different questions with different answers.

| DEC | What | Readiness |
|---|---|---|
| `DEC-106` | Incorporating disclosed food-access or affordability constraints | `BLOCKED` |
| `DEC-107` | Aligning default guidance to a named external standard | `COVERED` |

## The roadmap item is DEC-107, and it is already covered

The app cites named external standards throughout: Mifflin-St Jeor and DRI-style constants in the
calculations, and the `Kaynakları göster` sources map links NIDDK, NCBI Endotext, WHO and the National
Academies DRI tables.

Nothing to build. The only ongoing work is keeping that sources map accurate as the cited standards
change, which the energy individualization documents already flag in one place: the drafted
specification still cites 2005-era DRI activity bands, and whether to move to the 2023 framework is an
open decision there.

## Affordability itself stays blocked

`DEC-106` needs a food-access and affordability data model that does not exist. It is the same wall as
budget-aware shopping, `DEC-073`, where the register notes that inventing prices would be fabricated
data.

## MVP scope

In: nothing. Keep the sources map current.

Out: affordability and access constraints, `DEC-106`.
